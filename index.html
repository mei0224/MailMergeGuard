GOOD TO KNOW

Built for a safer handoff.

Are my documents uploaded?

No. Your chosen PDF and CSV are processed in the browser, and the ZIP is created on your device. The processing libraries are downloaded from a third-party CDN. See how file processing works and our privacy policy.

What if a name is not found?

You'll get a warning and can preview the page. OCR is not included: scanned PDFs and some unusual fonts can't be verified automatically.

Does it send PDFs by email?

No. MailMerge Guard only creates a ZIP download. Review all files before distributing sensitive documents.

What PDF layouts work?

Each person's document must use the same fixed number of consecutive pages. Encrypted or digitally signed PDFs are not supported.
