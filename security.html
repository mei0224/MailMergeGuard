SECURITY & TRANSPARENCY

Understand what happens
to your files.

MailMerge Guard is designed to process your PDF and CSV files in your browser. Here is how it works, how you can inspect it, and what it cannot guarantee.

01

You choose files

Your PDF and CSV are read through your browser's file APIs. Files selected from your computer are not uploaded to a MailMerge Guard application server by this code.

02

They are processed locally

The app parses the CSV, reads PDF text, checks names and splits pages in your browser. Some processing libraries are downloaded from the jsDelivr CDN. JSZip is provided by the site.

03

You download the result

Individual PDFs, a check report and the ZIP are generated in your browser. The app does not automatically email any documents.

Don't rely on a badge. Inspect the implementation.

The application code is directly available from this website. To inspect the HTML, use your browser's “View page source” option on the tool page. You can also examine browser network requests in developer tools when loading files and exporting a ZIP.

What network requests can still occur?

Your browser requests the website's HTML, CSS, JavaScript and processing libraries, including some fetched from the jsDelivr CDN. If you select Load included sample files, it also downloads the sample PDF and CSV from this site.

Web hosting providers may receive IP addresses and technical access logs when serving these files. No advertising or analytics scripts are included in this version of the app. The third-party CDN may receive technical request information, but not your selected documents from the application code. Local processing does not eliminate every risk posed by the hosting environment, browser or third-party code.

Important limits

  • Not a security certification. This application has not been independently security-audited. Do not treat it as guaranteed secure for confidential records.
  • Name found does not mean identity verified. A name can appear elsewhere on a page or be repeated. Manually check each document before distributing it.
  • Scanned PDFs may be unreadable. No OCR is provided; text extraction can fail even when a name is visible.
  • Some PDF features are unsupported. Password-protected, digitally signed or complex form PDFs may fail or lose behavior after splitting.
  • Local processing is not a backup. Reloading or closing the page discards analysis held in browser memory. Keep your original files.

Read the full privacy policy and limitations before using the tool with sensitive documents.
